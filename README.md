# 하이라이트 (HIGHLIGHT) 홈페이지

HAIWRITE의 HAI Essay를 품은 구독형 문학 플랫폼 「하이라이트」의 정적 웹사이트 시안입니다.
「하이라이트 HAI Essay 홈페이지 구축 기획안 v2.0」(2026.10.29)을 기준으로 만들었습니다.

## 실행

빌드 과정 없이 정적 파일로 동작합니다. 폴더에서 아래 명령을 실행한 뒤 http://localhost:5500 을 엽니다.

```bash
python -m http.server 5500
```

## 페이지

| 파일 | 내용 |
| --- | --- |
| `highlights.html` | 메인 — 대표 이미지(높이 100px) · 인트로 · 명예의 전당 · 인기 작품 · 다섯 가지 감상법 · HAI Essay · 웹진 · 아카데미 · 출판 · 구독 |
| `about.html` | 소개 — 하이라이트란 · 창작 철학 · 하이 에세이란 · H-A-I 모델 · 비교표 · 참여 방법 |
| `works.html` / `work.html` | 작품 목록(장르 탭·정렬) / 작품 상세(아이보리 읽기 화면, 좋아요·댓글, AI 낭독 시연, 플레이어) |
| `hall.html` | 명예의 전당 — 이달의 작품 · 월별 선정작 · 선정 기준 |
| `academy.html` | 아카데미 — 과정 카드, Google Forms 신청 링크 |
| `webzine.html` | 웹진 — 최신호 표지·목차 · 전체 호 · 발간 안내 |
| `publish.html` | 출판 — 원고 유무별 경로 · 상담 신청 |
| `subscribe.html` | 구독 — 요금제 선택 → 로그인 → 결제 → 활성화 |
| `login.html` / `mypage.html` / `write.html` | 로그인·회원가입 / 마이페이지 / 작품 등록(작가회원 전용) |

## 구조

- `css/style.css` — 색상·타이포·헤더·카드 등 공통 디자인 시스템
- `css/pages.css` — 페이지별 스타일
- `js/data.js` — 시범 작품·선정작·웹진·아카데미 데이터 (CMS/API로 교체할 부분)
- `js/common.js` — 헤더/푸터, 시범 회원 상태, 작품 카드
- `js/home.js`, `js/pages.js` — 메인 / 서브 페이지 동작

## 시범 동작에 대해

서버가 없으므로 로그인·구독·좋아요·댓글·작품 등록은 **현재 브라우저의 localStorage에만 저장**되는 시연용입니다.
결제(PG), 실제 인증, 파일 업로드, Google Forms 주소, 운영 주체 정보는 운영 확정 후 연결해야 합니다.
작품·작가·댓글은 모두 예시 콘텐츠입니다.
